# 휴대폰 테스트 안내

자동 테스트는 휴대폰 화면 크기를 흉내 낸 것(Chromium 360×740, iPhone 13 에뮬레이션)이고, 실제 기기에서는 확인하지 않았습니다. 이 문서는 실제 휴대폰에서 직접 확인하는 방법과 점검표입니다.

## 1. 준비

- 컴퓨터와 휴대폰이 **같은 공유기**에 연결되어 있어야 합니다. 컴퓨터는 유선이어도 되고, 휴대폰은 같은 공유기의 Wi-Fi에 연결하면 됩니다.
- 게스트 Wi-Fi나 "AP 격리"가 켜진 공용 Wi-Fi에서는 휴대폰이 컴퓨터에 접속하지 못합니다.
- 설치(`scripts/setup.sh` 또는 `scripts\setup.ps1`)를 마친 상태여야 합니다. README의 설치 절차를 참고하세요.
- 개발 서버에는 로그인 보호가 없습니다. 같은 네트워크의 누구나 접속할 수 있으므로 **믿을 수 있는 네트워크에서만** 사용하고, 끝나면 서버를 종료하세요.

## 2. 실행

저장소 루트에서 실행합니다.

macOS / Linux / Git Bash:

```bash
bash scripts/dev-lan.sh
```

Windows PowerShell:

```bash
powershell -ExecutionPolicy Bypass -File scripts\dev-lan.ps1
```

스크립트가 하는 일은 다음과 같습니다.

1. 컴퓨터의 로컬 네트워크 IP를 찾습니다. 가상 네트워크(WSL, Docker, VirtualBox, VPN 등)는 제외합니다.
2. 백엔드를 `0.0.0.0:8000`으로 시작하고, 그 IP를 `ALLOWED_HOSTS`와 CORS 허용 목록에 추가합니다.
3. 프론트엔드를 `vite --host`로 시작하고, `VITE_API_BASE`가 `http://<IP>:8000`을 가리키게 합니다.
4. 휴대폰에서 열 주소와 QR 코드를 터미널에 출력합니다.

휴대폰 카메라로 QR 코드를 스캔하거나 출력된 주소(예: `http://192.168.50.142:5173`)를 브라우저에 직접 입력합니다. 종료는 터미널에서 `Ctrl+C`입니다(프론트엔드와 백엔드가 함께 종료됩니다).

IP를 잘못 골랐다면 직접 지정할 수 있습니다.

```bash
LAN_IP=192.168.0.5 bash scripts/dev-lan.sh
```

PowerShell에서는 `$env:LAN_IP = '192.168.0.5'`를 먼저 실행한 뒤 스크립트를 실행합니다.

## 3. 접속이 안 될 때

| 증상 | 원인과 해결 |
| --- | --- |
| 페이지가 열리지 않고 시간이 초과됨 | 컴퓨터의 방화벽이 8000, 5173 포트의 외부 접속을 막고 있을 가능성이 큽니다. 아래 "Windows 방화벽"을 보세요. |
| `No LAN address found` | 컴퓨터가 네트워크에 연결되어 있지 않거나 가상 네트워크만 있습니다. 위의 `LAN_IP`로 직접 지정하세요. |
| 휴대폰과 컴퓨터가 다른 네트워크 | 휴대폰이 모바일 데이터나 게스트 Wi-Fi에 연결되어 있지 않은지 확인하세요. |
| 페이지는 열리는데 운동 목록이 비어 있고 "서버에 연결할 수 없습니다" 표시 | 백엔드(8000) 접속이 막힌 경우입니다. 휴대폰 브라우저에서 `http://<IP>:8000/api/exercises/`를 직접 열어 JSON이 나오는지 확인하세요. |
| `Port 5173 is already in use` | 이미 실행 중인 개발 서버가 있습니다. 종료한 뒤 다시 실행하세요. |

### Windows 방화벽

처음 실행하면 Windows가 `python.exe`와 `node.exe`의 네트워크 접근을 묻는 창을 띄울 수 있습니다. **"사설 네트워크"만 체크**하고 허용하세요.

창이 뜨지 않았는데도 접속이 안 되면, 관리자 권한 PowerShell에서 규칙을 추가할 수 있습니다. 이 규칙은 스크립트가 만들지 않으며, 직접 실행하는 경우에만 적용됩니다.

```bash
New-NetFirewallRule -DisplayName "GYM WIKI dev" -Direction Inbound -Protocol TCP -LocalPort 8000,5173 -Profile Private -Action Allow
```

테스트가 끝나면 다음 명령으로 제거합니다.

```bash
Remove-NetFirewallRule -DisplayName "GYM WIKI dev"
```

## 4. 테스트 중 알아둘 점

- 휴대폰에서 입력한 자가 점검, 완료 표시는 개발용 DB(`backend/db.sqlite3`)의 `demo` 사용자 데이터로 저장됩니다. 끝난 뒤 정리하려면 교정 센터에서 실수 노트를 삭제하고, 훈련 계획에서 완료 표시를 취소하세요.
- 계산기의 입력값과 결과는 서버로 전송되지 않습니다.
- 휴대폰 브라우저가 화면 회전을 잠그고 있으면 가로 화면 점검이 되지 않습니다. 회전 잠금을 해제하세요.
- 화면 크기는 기기마다 다릅니다. 가장 작은 기기(360px 안팎)와 큰 기기를 모두 확인하면 좋습니다.
